## 3. The five highest-leverage fixes

1. **Kill the scroll-wheel value mutation** (`fields.tsx:87`) — the only finding that can silently produce a *wrong engineering answer*, on a tool whose premise is traceable correctness.
2. **Wire labels to controls** (`fields.tsx:39` + call sites) — one `useId` fixes 23 orphaned labels, makes labels clickable, deletes 24 duplicated `aria-label`s.
3. **Reduced-motion block + light-theme ring fix** (`globals.css`) — two small CSS edits; clears guideline area #4 and lifts every focus indicator above 3:1; fold in the `inputs-panel.tsx:771` focus ring.
4. **Heading spine + live verdict on `/design`** — hidden `h1`, `CardTitle` as real headings, `role="status" aria-live="polite"` on the verdict strip.
5. **`next/dynamic` the two chart panels** — ~150 KB gzip off the critical path, and off ordinary-wall designs entirely.
